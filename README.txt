STUDENT MANAGEMENT FRONTEND

Files:
- index.html: page structure and registration form
- style.css: responsive visual design
- script.js: browser validation, success message, temporary session list

How to run:
1. Extract the ZIP file.
2. Open the student_management_frontend folder.
3. Double-click index.html, or open it with VS Code and use Live Server.
4. Fill in the required fields and click "Submit registration".

Important:
- This is frontend only. No backend or database is connected.
- Entries are shown temporarily while the page remains open.
- Refreshing or closing the page clears the entries.
- HTML browser validation checks required fields and email format.
